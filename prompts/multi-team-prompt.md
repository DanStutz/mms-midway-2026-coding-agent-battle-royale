“The Agent Builds Its Own Agent”
Scenario
Meta and fun for a conference.
Prompt
Design an AI agent that helps enterprise consultants deliver cloud migration projects.  
Define the agent’s purpose, personas it supports, tools it needs, memory model, permissions, workflows, escalation points, failure modes, audit requirements, prompt library, and evaluation criteria.  
Then create three example conversations showing how a consultant would use it.

Multi-Agent Version
Simulate a product team designing this consulting AI agent. Include agents for Product Manager, Enterprise Architect, Security Architect, UX Designer, Delivery Consultant, Data Engineer, and Legal/Compliance Reviewer.  
Have each agent contribute requirements, then synthesize the final product design.

Why This Is Good
It compares how models think about agents as products, not just chatbots.
